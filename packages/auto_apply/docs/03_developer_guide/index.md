# Developer Guide

Welcome, developer! We're thrilled that you're interested in the technical side of the AutoApply Agent. This project is built with a focus on modern, professional software architecture, and we hope it serves as a great example of a high-quality, open-source Python application.

This guide provides all the information you need to understand the project's design, set up your development environment, and contribute your own code.

---

### What You'll Find Here

This guide is for anyone who wants to understand *how* the agent works under the hood. It's broken down into several key sections:

1.  **Contribution Workflow:** The step-by-step process for reporting bugs, suggesting features, and submitting code via Pull Requests. This is the place to start if you want to contribute.
2.  **Project Setup:** Detailed instructions for setting up a complete development environment, including all testing and documentation tools.
3.  **Running Tests:** A guide on how to run the automated test suite to ensure your changes are safe and reliable.

For an even deeper look into the "why" behind the code, be sure to check out the **Architecture Deep Dive** section after this guide.
