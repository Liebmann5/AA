# Installation

Welcome to the AutoApply Agent! Follow these simple steps to get the application up and running on your local machine.

## Prerequisites

Before you begin, you must have the following software installed on your computer.

1.  **Python:** Version 3.9 or newer. You can download it from the [official Python website](https://www.python.org/downloads/).
2.  **Git:** Required for cloning the project repository. You can download it from the [official Git website](https://git-scm.com/downloads).

---

## Step-by-Step Installation

These instructions should be run from your computer's terminal (like PowerShell on Windows, or Terminal on macOS/Linux).

### 1. Clone the Repository

First, you need to download the project's source code. Open your terminal and run the following command to clone the repository to your machine:

```bash
git clone https://github.com/Liebman5/AA.git
   cd AA/packages/auto_apply
```
